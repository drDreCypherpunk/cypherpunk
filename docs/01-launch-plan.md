# Launch plan & copy pack

**Decided:** community is pre-launch, broad crypto/Web3 niche with a privacy-first
wedge, optimizing for engaged users over raw numbers, small budget, fast (weeks-scale)
spike. Hub = Discord, broadcast = X, plus Substack/Threads/Reddit as secondary channels.

Full ready-to-send copy lives in the **Launch Kit** artifact (see `README.md` for
link) — this file is the plan behind it.

## Phase 0 (days 1–3): Foundation
- One primary hub (Discord) + one broadcast channel (X) — not four platforms at once.
- One-line positioning statement: what makes this different from a generic "Web3
  community #4,821."
- Server skeleton: `#start-here`, `#general`, `#build-log`, `#alpha-and-drops`.

## Phase 1 (days 3–7): Seed with real people
- Personally recruit 20–30 seed members from adjacent Discords/X — quality over
  quantity; a copy-pasted opener gets ignored, personalize line 1.
- Give seed members a real reason to stay: early-access role, direct input on
  features, first look at drops.
- Start a public build log on X.

## Phase 2 (week 2): Engagement engine
- Daily low-effort touchpoint (poll, hot-take, "guess the next feature").
- Small budget → a bounty/quest program (invite, share, test, report bugs), not ads.
- 2–3 micro-influencer (5–20k followers) collabs instead of one big-name post.

## Phase 3 (weeks 3–4): The spike moment
- A forcing event (testnet drop, feature reveal, scarcity mechanic) — fast spikes
  need a trigger, not just steady posting.
- Cross-post into 2–3 adjacent communities with context, not spam.
- North-star metric: **72-hour return rate of new joins**, not join count — that's
  what separates community from airdrop-farm.

## Copy pack contents (see Launch Kit artifact)
1. Seed recruitment DM + follow-up message
2. X launch thread (4 tweets)
3. Substack origin-story post ("Why we're building Cypherpunk")
4. Threads posts (2 shorter variants — looser register than X)
5. Reddit launch posts (2 versions — one substance-led for r/CryptoTechnology,
   one framed as a discussion question for bigger subs like r/ethereum)

Every `[bracket]` in the copy is a placeholder (invite link, handle, concrete
product detail) that must be filled in before sending — un-filled brackets are
the fastest way to look like spam, especially on Reddit.
